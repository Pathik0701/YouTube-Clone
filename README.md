# YouTube Clone 🎬

A simple YouTube Clone built using **HTML and CSS** to practice front-end web development concepts.

## 🚀 Features
- Header with navigation bar
- Sidebar menu
- Video thumbnails layout
- Clean YouTube-style UI
- Responsive design (basic)

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📂 Project Structure
- `index.html` – Main HTML file
- `youtube-styles/` – CSS files
- `icons/` – Icons used in the UI
- `thumbnails/` – Video thumbnails
